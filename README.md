# Dissertation Obsidian Vault

This repository is an Obsidian documentation vault for a cybersecurity master's dissertation on privacy-preserving browser caching for medical-image viewing in the Dicoogle-next ecosystem.

## Start here

Open [[Home]] in Obsidian.

## Vault structure

- `Home.md`
- `README.md`
- `.obsidian/`
- `Architecture/`
- `Specification/`
- `Research/`
- `diagrams/`

## Open as an Obsidian vault

1. Open Obsidian.
2. Choose **Open folder as vault**.
3. Select this repository root.
4. Start from `Home.md`.

## Draft and validation limits

Notes distinguish proposed/planned items from verified outcomes. Requirements, controls, and evaluation claims must remain explicitly qualified until implementation/tests are confirmed.
